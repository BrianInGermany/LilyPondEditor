What's supported
  • Pitches & octaves: Dutch names (fis, bes, es, cisis), ' ,, \relative, \fixed, \transpose, forced accidentals ! ?
  • Rhythm: durations 1–128 and \breve, dots, *n/m, \tuplet 3/2, \times, \partial, rests r, full-bar rests R1*4, spacers s
  • Chords: <c e g>4, chord repeat q, \arpeggio
  • Lines: ties ~, slurs ( ), phrasing slurs \( \), manual beams [ ] plus automatic beaming, \autoBeamOff
  • Expression: dynamics \pp … \fff \sfz \fp, hairpins \< \> \!, articulations -. -> -- -^ -! -_ and \fermata \trill \accent \staccato \marcato \turn \mordent \upbow \downbow…, fingerings -1, text ^"dolce" _\markup{…}, direction ^ _
  • Grace notes: \grace, \acciaccatura, \appoggiatura, \afterGrace
  • Structure: \clef (treble, bass, alto, tenor, soprano, treble_8…), \key … \major/\minor/\dorian…, \time, \tempo, \bar, \mark \default, \break, \repeat volta + \alternative (played with repeats), \repeat unfold
  • Voices & staves: << { } \\ { } >>, \new Voice, \new Staff, \new PianoStaff, GrandStaff, StaffGroup, ChoirStaff, \voiceOne…, \stemUp…
  • Chord names: \chordmode, \chords, \new ChordNames; c:m7 g:7 f:maj7 b:m7.5- e:7.9- d:sus4 c:dim7 a:aug c:13 c/e c/+b c:9^7; rests print N.C.; chords are played back, and \chordmode in a normal staff prints the notes
  • Lyrics: \addlyrics, \new Lyrics \lyricsto "name", hyphens --, extenders __, skips _, several verses
  • Files: variables (melody = { … } then \melody), \score, \header (title, composer…), comments % %{ %}; \layout, \midi, \paper, \override, \set are accepted and ignored
  • Not supported: Scheme code, fret diagrams, drums, tablature, figured bass, cross-staff notes, ottava lines, markup layout. Line breaks and spacing are this page's own, not LilyPond's.
MIDI QR code

The code holds the song as a standard MIDI file written as base64 text (it starts with TVRoZ). Any QR scanner reads it as text. To listen, paste the text into any base64 decoder, save the result as song.mid, and open it in a MIDI player. Print it at least 4–5 cm wide.
